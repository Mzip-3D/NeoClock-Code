# NeoClock-Code
CircuitPython code for 3d-printed Neopixel Clocks

This code is built for neopixel clock projects I have created and posted on MakerWorld. These clocks use the Adafruit PropMaker board built on the RP2040 which has an audio amplifier, neopixel output, accelerometer, button input, and all the regular RP2040 peripherals.

The code specific to the clocks is my own but it is built on code supplied by Adafruit for projects they feature at learn.adafruit.com. They published under the MIT license so this code is also under MIT license.

It's not updated with the newer libraries yet.
